# Changelog

## 0.1.1

- Keep the drag wheel hidden during Command-Tab app switching; retain normal Command tool activation.
- Add a short animated tools-wheel demo.

## 0.1.0-preview.6 — 2026-10-19 (contributor preview)

- Native, offline workspace with 28 tools, 275 conversion routes and six file actions.
- Drag wheel offers all tools compatible with the current selection.
- Image/video crop previews, audio waveforms, PDF organization and local Vision OCR.
- Pages and Creator Studio conversion support; native AppKit media playback.
- Readable opaque surfaces and the closed tangerine mark in the original style.
- Atomic output publication, original preservation and bounded archive extraction.
- OGG encoder fallback and transparent GIF-to-WebM compatibility with newer FFmpeg.
- `Tangerine-Studio.dmg` with a custom drag-into-the-wheel installation layout.
- Contributor documentation, fixture tests and reproducible app/installer builds.
- Removed Dependabot configuration and redundant generated reports.

See [capabilities](docs/FEATURES.md) and [verification](docs/VERIFICATION.md).
259 routes passed generated checks; all 16 Pages routes passed separate UI tests.
Signing/notarization, dependency-source audit and clean-Mac validation remain release
gates. This contributor build is ad-hoc signed and not notarized.
